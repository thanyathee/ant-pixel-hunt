# มดเก็บพิกเซล

เกมปริศนาเก็บพิกเซลด้วยฝูงมด เล่นในเบราว์เซอร์ ไม่มีโฆษณา

เล่นได้ที่ https://thanyathee.github.io/ant-pixel-hunt/

## วิธีเล่น

แตะกล่องแถวล่างเพื่อส่งมดไปเก็บพิกเซลสีเดียวกัน มดออกจากรูใต้ถาด เดินเลาะขอบเข้าไปกินเฉพาะพิกเซลที่มีทางเข้าถึง แล้วคาบกลับมาส่งที่กล่องของตัวเอง เก็บครบทุกพิกเซลคือผ่านด่าน

ช่องวางกล่องมีจำกัด ถ้าวางจนเต็มแล้วไม่มีกล่องไหนเข้าถึงสีของตัวเองได้ ถือว่าไปต่อไม่ได้ ต้องเริ่มด่านนั้นใหม่

## ความยาก

| ด่าน | ช่องวางกล่อง | เห็นกล่องล่วงหน้า |
|---|---|---|
| 1–5 | 6 | 3 ใบ |
| 6–30 | 5 | 3 แล้วลด 2 ใบ |
| 31–60 | 4 | 2 แล้วลด 1 ใบ |
| 61 ขึ้นไป | 3 | 1 ใบ |

- มีรูปอาหารไม่ซ้ำกัน 120 รูป แต่ละรอบพลิกซ้ายขวา พลิกบนล่าง และหมุน 90 องศาสลับกันไป รวม 8 แบบต่อรูป ประมาณ 960 ด่านจึงเริ่มซ้ำ
- ด่าน 30 ขึ้นไป รูปทรงใหญ่ถูกแบ่งเป็นด้านสว่างกับด้านเงา โดยสีเงาเลื่อนโทนไป 30–60 องศา เป็นคนละกล่องกัน
- ด่าน 41 ขึ้นไป พื้นหลังปูเต็มถาด ต้องกินพื้นหลังเปิดทางก่อน ด่าน 60 ขึ้นไปพื้นหลังเป็น 2 แถบสี ด่าน 160 ขึ้นไปเป็น 3 แถบ
- ด่าน 101 ขึ้นไป รูปวาดที่ความละเอียด 2 เท่า พิกเซลเล็กลง จำนวนมากขึ้น
- ด่าน 120 ขึ้นไป มีหินที่เก็บไม่ได้ มดต้องเดินอ้อม
- ด่าน 180 ขึ้นไป มีกล่องปริศนาที่ไม่บอกสีจนกว่าจะวางลงช่อง

ทุกด่านผ่านการทดสอบด้วยตัวแก้อัตโนมัติแล้วว่ามีทางเล่นชนะ ถ้าด่านไหนวางกล่องแล้วตัน ระบบจะจัดลำดับกล่องใหม่ให้เอง

## จานสี

สีทั้ง 33 สีถูกค้นหาด้วยการวัดระยะห่างแบบ CIE-Lab โดยบังคับว่าสีแต่ละสีขยับจากค่าเดิมได้ไม่เกินนิดเดียว สีแดงต้องยังแดง เขียวต้องยังเขียว แล้วดันทุกคู่ให้ห่างกันมากที่สุด ผลคือคู่ที่กลืนที่สุดในจานห่างกัน 32.7 หน่วย และเมื่อตรวจกระดานจริง 600 ด่าน ไม่มีด่านไหนมีคู่สีที่ห่างกันต่ำกว่า 30

## เซฟ

ความคืบหน้าเก็บไว้ใน `localStorage` ของเบราว์เซอร์ที่เล่น ทั้งด่านที่ปลดล็อกและสถานะกลางด่าน เกมบันทึกทุก 2 วินาทีและตอนปิดหน้า ล้างข้อมูลเว็บไซต์เมื่อไหร่เซฟหาย

ถ้าเปลี่ยนเครื่องหรือเบราว์เซอร์ ใช้ช่อง "ไปด่าน" ในเมนูด่านพิมพ์เลขด่านที่เล่นถึงเพื่อเล่นต่อได้เลย

## ติดตั้งบนหน้าจอโฮม

เปิดลิงก์ใน Safari (iPhone) หรือ Chrome (Android) แล้วเลือก "เพิ่มไปยังหน้าจอโฮม" จะได้ไอคอนมดและเปิดแบบเต็มจอเหมือนแอป

## โครงสร้าง

ทั้งเกมอยู่ใน `index.html` ไฟล์เดียว ไม่มี build step ไม่มี dependency นอกจากฟอนต์ Mitr จาก Google Fonts (ถ้าโหลดไม่ได้จะใช้ฟอนต์ของเครื่องแทน)

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวเกมทั้งหมด — วาดรูป, สร้างด่าน, ตัวแก้อัตโนมัติ, การเดินของมด, เซฟ |
| `manifest.webmanifest` | ข้อมูลสำหรับติดตั้งเป็นแอปบนหน้าจอโฮม |
| `apple-touch-icon.png` | ไอคอนบนหน้าจอโฮมของ iPhone |
| `icon-192.png`, `icon-512.png` | ไอคอนสำหรับ Android และ manifest |
